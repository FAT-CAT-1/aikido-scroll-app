# 第1章 合氣道の沿革

## 1-1 開祖・植芝盛平の生涯
[[植芝盛平]]（うえしば もりへい、1883年〈明治16年〉12月14日－1969年〈昭和44年〉4月26日）は、和歌山県西牟婁郡西ノ谷村（現・田辺市）の富裕な農家に生まれた（出典：Wikipedia「植芝盛平」、kotobank）。合気道界では「[[開祖]]（かいそ）」または「[[翁]]（おう）」と敬称される。

### 大東流と武田惣角
大正4年（1915年）、北海道遠軽の旅館で[[大東流合気柔術]]の達人[[武田惣角]]と出会い、その技に完敗して門人となった（出典：大東流合気柔術眞武館、えんがるストーリー）。約5年間熱心に修行し、開拓団と暮らす白滝村に武田を招くほど傾倒した。大正11年（1922年）、綾部で武田から「大東流合気柔術教授代理」の資格を授与された（出典：大東流合気柔術眞武館、Wikipedia）。後年、盛平は目録から大東流・武田惣角の名を外していったが、合気道技の原型が大東流にあることは研究者スタンレー・プラニンも指摘している（出典：合気ニュース／どう出版）。

### 大本教と出口王仁三郎
大正8年（1919年）、重病の父を見舞う途上、京都府綾部に立ち寄り、[[大本教]]の実質的教主[[出口王仁三郎]]に邂逅、深く帰依した。大正9年（1920年）、一家で綾部へ移住し大本に入信、私塾「植芝塾」を開設した（出典：kotobank、Wikipedia、武産通信）。王仁三郎の命名により自らの武術を「合気武術」と称し、言霊学の研究に没頭した。綾部修行中に「黄金体験（黄金の光に包まれ宇宙と一体化する神秘体験）」に遭遇し、「気の妙用」「[[万有愛護]]」の理念に達したとされる（出典：Wikipedia「合気道」）。

### 上京・皇武館・岩間時代
昭和2年（1927年）、王仁三郎の勧めもあり東京へ移住し、武田・大東流から徐々に距離を置いた。昭和6年（1931年）、東京・若松町に[[皇武館]]道場を開設。昭和15年（1940年）、財団法人[[皇武会]]設立。この前後から「合気武道」を名乗った。戦時中は陸軍憲兵学校・陸軍中野学校・海軍大学校などで武術指導を行った。昭和17年（1942年）、茨城県岩間町（現・笠間市）に移り、[[合気神社]]と合気修練道場（[[岩間]]道場）を建設。ここで「[[武産合気]]（たけむすあいき）」を深めた（出典：植芝盛平翁について ueshiba-morihei.com、Wikipedia）。

## 1-2 「合気道」という名称の成立
「合気道」という固有名称が制度上初めて確認できるのは昭和17年（1942年）である。戦時統制策により皇武会が政府外郭団体・[[大日本武徳会]]の統制下に入り、武徳会に設置された「合気道部」で「大日本武徳会合気道」が制定された時である（出典：Wikipedia「合気道」「光輪洞合気道」）。命名は講道館出身で武徳会役員の久富達夫が主唱したと平井稔が証言している。剣杖を含む総合武術部門として構想された。植芝側はそれまで「合気武術」「合気武道」を経て、便宜上「合気道」を名乗るに至った。

昭和23年（1948年）、名称を皇武会から改め、文部省の認可を受けて**財団法人合気会（初代理事長・富田健治）**となり、「合気道」の名称が確立した（出典：Wikipedia「合気会」、note「合気道という名称」）。

**「合氣道」の表記について**：戦後の当用漢字で「気」が用いられるが、開祖の系統を重んじる会派や心身統一系などでは旧字「氣」を用いる道場がある。字義として「气＋米（八方に広がる米）」を重んじて「氣」を用いるという立場である（稽古上の解釈）。本アプリ名も「合氣道」表記を採用している。

## 1-3 二代・三代道主と本部道場長
- **[[植芝吉祥丸]]**（うえしば きっしょうまる、1921年6月27日－1999年1月4日）：開祖の三男。1948年頃から本部道場長。1967年に財団法人合気会理事長、1969年（開祖逝去）に二代道主を継承した（出典：Wikipedia「植芝吉祥丸」）。戦後の合気会は入門者が集まらず養神館に劣勢だったが、吉祥丸は普及に尽力した。1950年に機関紙『合気会報』（後の『合気道新聞』）を創刊、1956年に髙島屋東京店（日本橋店）屋上で合気道初の一般公開演武、1960年に第1回全日本合気道演武大会を開催、1962年に開祖監修・吉祥丸著の初の一般向け技術書『合気道』を出版した。
- **[[植芝守央]]**（うえしば もりてる、1951年4月2日生）：吉祥丸の次男、三代道主。1976年明治学院大学経済学部卒。1985年専務理事、1996年理事長、1999年（吉祥丸逝去）に道主継承。著書『合気道 その歴史と技法』ほか（出典：合気会公式、WEB秘伝、ベースボール・マガジン社）。
- **[[植芝充央]]**（うえしば みつてる）：守央の長男、開祖を曾祖父にもつ。現・公益財団法人合気会 合気道本部道場長（出典：trendaqua、合気会）。

## 1-4 組織：合気会・IAF
[[合気会]]は、2012年に公益財団法人へ移行した。本部道場は昭和6年に開設された。[[国際合気道連盟]]（[[IAF]]、International Aikido Federation）は1976年設立、本部は東京にあり、会長は常に道主（現・植芝守央）が務める（出典：Wikipedia「IAF」、IAF公式）。加盟は各国1組織を原則とし、すべて本部（Aikikai）の承認を要するため、IAFは事実上合気会を代表する。英語版Wikipediaによれば加盟は2024年4月に87か国に達し、うち13は議決権のない準加盟である。なお2024年10月の第14回東京大会時点では加盟88か国とする報道もある（出典：budojapan.com）。同じ1976年5月には全日本合気道連盟も合気会の補助組織として設立された（出典：eurasiaaikido.org）。

## 1-6 大学合気道の歴史
1955年頃、明治神宮武道場「[[至誠館]]」初代館長の田中茂穂が、道場の違いを超えて大学合気道部の横のつながりを図るため連盟結成を提唱した。当時東京大学合気道部主将だった亀井静香らが中心となり、1959年5月に学生合気道連盟準備会が発足した（出典：weblio、全日本学生合気道連盟）。会長の人選をめぐる大学間の対立から、1961年6月26日に工藤昭四郎を会長、亀井静香を委員長とする[[全日本学生合気道連盟]]が発足した。一方、これを離脱した合気会系の部が同年[[関東学生合気道連盟]]（後の[[全国学生合気道連盟]]）を結成した（出典：weblio）。

**獨協大学合気道部は、この関東学生合気道連盟系（＝合気会系）に位置づけられる。**

- **全国学生合気道連盟**：公益財団法人合気会内に存在し、北海道・東北・関東・中部・関西・中四国・九州の各地域に分かれて活動する。関東部門が関東学生合気道連盟である（出典：関東学連公式、Wikiwand）。
- **全国学生合気道演武大会**：毎年11月末に日本武道館で開催される学生の全国大会（第64回＝2025年11月29日開催、合気会本部師範の指導による稽古錬成も実施）（出典：関東学連公式）。
- **全日本合気道演武大会**（合気会主催）：1960年（昭和35年）に第1回開催。近年は約7,000〜7,500名規模の参加者を数える（出典：日本武道館月刊『武道』、合気道人植会告知）。

# 第2章 基本理念・思想

## 2-1 「合気」と和合
「合気道」とは「天地の“気”に合する道」の意とされる（出典：weblio）。開祖は「合気とは敵と闘い敵を破る術ではない。世界を和合させ人類を一家たらしめる道である。即ち、合気道の極意は、おのれを宇宙の動きと調和させ、おのれを宇宙そのものと一致させることにある」と説いた（出典：京都大学合気道部、合気道田中道場）。理念の中心は[[和合]]・[[万有愛護]]・「武は愛なり」であり、盛平は「合氣とは愛なり」と語ったと伝わる（出典：Wikipedia「合気道」）。

## 2-2 武産合気（たけむすあいき）
[[武産合気]]は「無限なる技を産み出す合気」と表現され、自分と相手・自分と宇宙との和合により可能になるとされる（出典：Wikipedia）。開祖は戦後、岩間で完成させた武道を「武産合気道」と称したという説がある（出典：合気ニュース／どう出版。ただしこの命名の一次資料の確認は限定的で、解釈に幅がある＝稽古上の解釈）。

## 2-3 道歌・語録
開祖は多くの[[道歌]]を詠んだ。例：
- 「神ながら合気のわざを極むれば如何なる敵も襲うすべなし」
- 「天地人和合の守り合気道大海原は祝ぎの音」
（出典：asahi-net「植芝盛平先生がつくられた道歌」、阿部醒石編『合気道奥義』）

道歌は言霊学・大本教の宇宙観を色濃く反映しており、その解釈は諸説ある（稽古上の解釈）。開祖は「武における業はすべて宇宙の真理に合わせねばならぬ」とも語った（出典：坪内隆彦サイト）。

## 2-4 試合を行わない理由と演武
合気会は理念上、勝敗を争うことを否定し試合を行わない。稽古は主に「形（かた）」の反復と、定期的な[[審査]]・[[演武]]会で構成される。相手と優劣・勝敗を決める競技はない（出典：合気会公式）。海外研究者スタンレー・プラニンは「受けは clean ukemi を、取りは clean waza を行い、妨害や試しはしないという了解のもとに稽古する」と述べている（出典：Aikido Journal "When is Aikido Not Aikido?"）。※富木流のみ競技化している（会派差）。

## 2-5 礼法
合気道は[[座礼]]を礼法の基本とし、[[正座]]が座ったときの基本姿勢である（出典：日本武道館『合気道指導書』）。稽古の流れの一例：
1. 道場入退場時に[[神前]]（神棚）へ礼
2. 稽古開始時に「[[正面]]に礼（shomen ni rei）」
3. 「[[師範]]（先生）に礼（sensei ni rei）」
4. 「お互いに礼（otagai ni rei）」
5. 稽古相手との手合わせ前後にも座礼

（出典：Northwestern Aikido FAQ、合気道諸道場）。神前への礼を二礼四拍手一礼とする道場例もある（道場差）。座る時は左足から、立つ時は右足からとするのが武道一般の作法である。座礼は約30度、相互礼は約15度など角度の目安がある（剣道・柔道と共通する説明）。

## 2-6 稽古の心得と段階
- **受身の重要性**：合気道の稽古の半分は「壊れずに受けること」を学ぶことにあるとも言われる（出典：合気道産靈 用語集）。
- **受けが取りを育てる**：受けは正しい攻撃・素直な受身によって取りの上達を助ける（一般的な指導）。
- **稽古の段階**：固い稽古 → 柔らかい稽古 → 流れの稽古 → 気の流れ、と進むという整理が一般的（稽古上の解釈、師範により表現が異なる）。岩間系は基礎の「固い稽古」を重視し、合気会本部・吉祥丸系は「流れ」を重視する傾向がある（会派・師範差）。

## 2-7 武道としての身体観
[[丹田]]（臍下丹田）、[[正中線]]・[[中心線]]、[[呼吸力]]、[[気]]、[[入身]]・[[転換]]、[[間合い]]、[[残心]]、[[目付け]]。合気道は「入身・転換の体捌きを用い、合気と呼吸力による技で、一呼吸の内に相手を制する」と要約される（出典：坂戸合気会「稽古者視点から合気道を考える」）。理想の間合いは、相半身に構えた掌と掌の間隔が拳一個程度とされる（同）。

# 第3章 基礎動作（6部位解説付き）

各項目は「概要 → 6部位（目／顔／肩／腹・帯の向き／膝／足）の一言解説 → 詳細（階層2）→ 超詳細（階層3）」で記述する。※content-spec.md では5階層に拡張する。

## 3-1 構え（[[半身]]）
### 概要
合気道の基本の構えは[[半身]]。相手に対し体を斜めにして正面の面積を減らし、[[当身]]をかわしやすくする（出典：合気道ブログ「半身について」）。右足前が[[右半身]]、左足前が[[左半身]]。互いに同じ側の足を前にするのが[[相半身]]（ai hanmi）、異なる側が[[逆半身]]（gyaku hanmi）。無構えに近い自然体をとる師範もいる（塩田剛三は無構えを説いた／会派差）。
### 6部位一言解説
- **目**：相手全体をぼんやり見る（[[遠山の目付け]]）。一点を凝視しない。
- **顔**：相手正面へ向けるが力まない。
- **肩**：力を抜いて落とす（撫で肩）。
- **腹/帯**：丹田を相手へ向け、正中線を保つ。
- **膝**：わずかに緩め、居着かない。
- **足**：前足つま先を相手へ、後ろ足は約60〜90度開く。
### 詳細（階層2）
半身は転換・転身の起点であり、技の前後で半身から半身へ移る（出典：合気道ブログ）。重心は低く保つ。
### 超詳細（階層3）
- **よくある誤り**：肩に力が入る／後ろ足が伸びきる／目線が手元に落ちる。
- **上級者の視点**：構えは「形」ではなく「いつでも動ける状態」。
- **師範による違い**：養神館は前足つま先を外へ、後ろ足を約90度とする明確な[[構え]]（kamae）を規定。合気会は比較的自由。

## 3-2 足捌き・体捌き（[[体捌き]]、tai sabaki）
- [[送り足]]（okuri ashi）：後ろ足で前足を送る。
- [[継ぎ足]]（tsugi ashi）：後ろ足を前足に継ぐ。
- [[歩み足]]（ayumi ashi）：通常歩行のように左右交互。
- [[転換]]（tenkan）：前足を軸に後ろ足を180度回す。視線の方向は180度変わる（出典：八千代円明会）。
- [[入身]]（irimi）：直線に近い螺旋で相手側面（死角）へ踏み込む。視線は変わらない。
- [[転身]]（tenshin）：後ろ足を斜め前に移し、腰の回転で半身を入れ替える。視線は変わらない。
- [[転回]]（tenkai）：半身のまま両足先を軸にその場で向きを変える。
- [[入身転換]]（irimi tenkan）：入身と転換の連結。

## 3-3 体の変更（[[体の変更]]、tai no henko）
片手取りから、掴まれた手と同じ半身の足で相手足の外側へ半歩入身し、その足を軸に180度背転して相手と同方向を向く鍛錬法（出典：weblio）。静的（相手が強く持って止まる）と流動的（動きの中で行う）がある。「[[体の転換]]」「入身転換」とも呼ばれる。

## 3-4 [[膝行]]（しっこう、shikko）
座技の移動法。前進・後退・回転。腰の回転を使い、足先は近づけて保つ（出典：USAF nomenclature）。膝と丹田を意識し、頭の高さを一定に保つ。

## 3-5 [[受身]]（うけみ、ukemi）
- [[後ろ受身]]（ushiro ukemi）
- [[前回り受身]]（mae ukemi、前方回転受身）
- [[飛び受身]]（跳躍受身）
- [[横受身]]
- [[後ろ回り受身]]
### 6部位一言（前回り受身）
- **目**：自分のへそを見る（顎を引く）。
- **顔**：正面を打たないよう横向き。
- **肩**：丸く張り、点で接地。
- **腹/帯**：丸める。
- **膝**：低く曲げる。
- **足**：小指側から手→肩→反対腰へ斜めに接地（出典：aikido-practice）。
### 超詳細
後ろ回り受身は後頭部保護のため必須。撞木足で立ち後ろ脚膝をつくと体が斜めになり、その斜めを保って肩で回る（出典：aikido-shiga）。練習順序は「しゃがんだ状態→立位→回転→跳躍」（出典：aikido-practice）。

## 3-6 [[手刀]]・握り・[[手の内]]
[[手刀]]（しゅとう、tegatana）は手を刀に見立てた接触面。多くの技で接触点を手刀で保ち、[[円転の理]]で相手重心を導く（出典：Wikipedia「合気道」）。

## 3-7 [[呼吸法]]
- [[座技呼吸法]]（[[呼吸動作]]、kokyu dosa／zagi kokyuho）：正座で両手首を掴ませ、指先を上に向け手刀を振り上げて相手を崩す（出典：weblio）。
- [[諸手取り呼吸法]]（morotetori kokyuho）
- **立ち技呼吸法**：半身の入れ替えで相手中心を捉え、入身して崩す（出典：合気道ブログ）。

## 3-8 準備運動・[[鳥船]]・[[振魂]]
[[鳥船]]（とりふね、funakogi undo／天の鳥船）と[[振魂]]（ふりたま）は大本教由来の禊（みそぎ）動作で、多くの合気会系道場が準備運動に採り入れる（出典：USAF nomenclature、多田宏系の「気の錬磨」）。[[一教運動]]（ikkyo undo）等の手首・肩の運動も定番。

## 4-4 技の徹底解説

> 各技は【技名（日/英）→概要→取り動作分解→取り6部位→取り詳細/超詳細→受け動作分解→受け6部位→受け詳細/超詳細→表裏の違い→関連技→用語】の順。技名は「攻撃法＋技」で命名される（例：正面打ち一教）。

### 4-4-1 [[一教]]（いっきょう）
- **技名**：一教／英 Ikkyo, First Teaching, First Control, Arm Pin。別称[[腕抑え]]（ude osae）。語源：「一」＝順序の最初、基本のベース（出典：佐々木合気道研究所）。
- **概要**：相手の肘関節を伸展させ腹這いに抑える固め技。5級（正面打ち一教）で登場。二〜四教の土台。「捌きは一教から四教まで同じ、後は手首操作」と言われる（出典：aiki10.com）。

**【取り】動作分解（正面打ち一教・表）**
1. 相半身で対峙、相手の正面打ちに合わせ後ろ足を踏み込み、当身の意で相手の肘と手首を制する。
2. 肘を突き上げながら少し腰を切り、進路を確保。
3. 後ろ足を大きく踏み込み、突き上げた手を前へ下ろし相手を前方へ落とす（相手に近い足が脇下へ）。前足つま先は相手へ。
4. 後ろ足を斜め前へ、相手の腕を斜め前に伸ばす。
5. 跪座で極め：両手を肘と手首に、膝を脇腹と手首にあてる（出典：aikido-fransowa）。

**【取り】6部位一言解説**
- 目：相手全体を制するつもりで見る。
- 顔：相手正面へ、崩す方向へ意識。
- 肩：抜いて落とす。腕力で押し上げない。
- 腹/帯：丹田を相手中心へ向け、体重を乗せる。
- 膝：極めで跪座、相手に近い足から着く。
- 足：手足同時に出す。ばらつかせない。

**【取り】詳細（階層2）**：崩しが命。肘を制して相手の重心を前へ導く。腕の力ではなく体重移動と入身で。

**【取り】超詳細（階層3）**
- よくある誤り：手先だけで押す／足が止まる／腰が高い。
- 修正法：一教運動で軌道を反復、足と手を同期。
- 師範による違い：本部系は流れの中で肘を上げる、岩間系は接触点で相手を止めてから確実に崩す。
- 安全：肘を極める際は反動をつけない。

**【受け】動作分解**：正面打ちを出す→肘・手首を制され前へ崩される→前へ導かれうつ伏せ→肘を伸ばされ抑えられる→跪座で極められる。極めは手を畳から離さず素直に従う。

**【受け】6部位一言**：目＝取りを見失わない、顔＝畳に打たない（横向き）、肩＝脱力し肘の伸展に逆らわない、腹/帯＝素直にうつ伏せへ、膝＝崩れに合わせ着く、足＝踏ん張り過ぎない（肘故障防止）。

**【受け】詳細・超詳細**：危険な受け方＝肘を突っ張って抵抗すると肘・肩を痛める。良い受け＝崩れの方向へ素直に、痛みが出る前にタップまたは受身。

**表裏**：表＝相手正面へ入身し前方へ崩す。裏＝相手側面（死角）へ転換し背後へ回して崩す（出典：oshiete.goo、fransowa）。

**関連技**：二教・三教・四教、[[入身投げ]]・[[小手返し]]への変化。
**用語**：[[表]] [[裏]] [[崩し]] [[跪座]] [[当身]]

### 4-4-2 [[二教]]（にきょう）
- **技名**：二教／英 Nikyo, Second Control, Wrist Lock。別称[[小手回し]]（kote mawashi）。
- **概要**：一教で崩した後、手首を内側に巻き込み手関節を極める固め技。4級（肩取り二教）等。

**【取り】動作分解（肩取り二教・表、出典：fransowa）**
1. 逆半身、受けが肩（道着）を掴む。
2. 後ろ足を出し下から拳で当身。
3. 反対足を引き胸を開き、当身の手で相手腕を斬り下ろす。
4. 相手の手に上からかぶせて掴み、小指を手首にかけ親指の付け根を押さえる（＝二教にとる）。
5. 肘を突き上げ一歩前へ落とし、斜め前へもう一歩、跪する。
6. 極め：手を肩につけ、当身をもらわぬよう外側で極める（出典：aikidomemo）。

**【取り】6部位一言**：目＝相手全体、顔＝外側に開く、肩＝抜く、腹/帯＝相手頭方向へ回す（表）、膝＝閉めて極める、足＝一教と同じ捌き。

**【取り】超詳細**
- よくある誤り：手首だけで極めようとする／一教の崩しが甘い。
- 師範差：極めの角度・方向に道場差が大きい。
- 安全：二教は激痛を伴う。ゆっくり、相手のタップで直ちに緩める。

**【受け】**：掴む→崩される→手首を極められ膝立ち→痛みで従い、うつ伏せに抑えられる。危険＝手首を固めて逆らうと手関節・肘を痛める。良い受け＝極めに従い体を落とす。
**表裏**：表は一教同様に前へ、裏は後ろへ膝行しながら崩す（出典：aikidomemo）。
**用語**：[[二教の極め]] [[小手回し]]

### 4-4-3 [[三教]]（さんきょう）
- **技名**：三教／英 Sankyo, Third Control。別称[[小手捻り]]（kote hineri）。
- **概要**：手首を捻り上げ、肘・肩・体幹まで極めて崩し腹這いに抑える固め技。3級（正面打ち三教）等。

**【取り】動作分解**：一教で崩す→相手の手を三教に持ち替え（親指側から握り手首を螺旋に捻り上げ）→捻りで相手を居着かせ→回して腹這い→肘を制し抑える。
**【取り】6部位一言**：目＝相手全体、顔＝捻り上げ方向、肩＝抜く、腹/帯＝螺旋に合わせ回転、膝＝抑えで着く、足＝捻りと同期して回る。
**【取り】超詳細**
- よくある誤り：手首を握り込みすぎ捻れない／腕を上げるだけで体幹に効かない。
- 師範差：握り替えの手順が異なる。握手状態からでも掛けられる（出典：okwave）。
- 安全：肩関節を痛めやすい。急激に上げない。
**【受け】**：捻りに従い背伸び→回されうつ伏せ。逆らうと手首・肩損傷。
**表裏**：入身の表、転換の裏。
**用語**：[[三教]] [[小手捻り]]

### 4-4-4 [[四教]]（よんきょう）
- **技名**：四教／英 Yonkyo, Fourth Control。別称[[手首抑え]]（tekubi osae）。
- **概要**：一教の捌きで崩し、前腕の橈骨神経付近を人差し指付け根で圧して制する。四級以降・座技で頻出。「ツボを抑えて崩す」（出典：aikido-practice）。
**【取り】6部位一言**：目＝相手全体、顔＝崩す方向、肩＝抜く、腹/帯＝体重を接触点へ、膝＝抑えで着く、足＝一教と同じ。
**【取り】超詳細**
- よくある誤り：握力で押さえる（効かない）。手の内の骨で「点」で当てるのがコツ（師範差大）。効きに個人差が大きい。
- 安全：神経圧迫のため長時間かけない。
**【受け】**：崩れに従う。良い受けは接触点を追う。表裏あり。
**用語**：[[四教]] [[手首抑え]]

### 4-4-5 [[五教]]（ごきょう）
- **技名**：五教／英 Gokyo。別称[[腕伸ばし]]（ude nobashi）。
- **概要**：一教の変形で、手首を下から取る（逆手持ち）。短刀取りなど刃物対処に用いる（刃を返す持ち方）。一級・二級（横面打ち五教）で登場。
**【取り】超詳細**：短刀取りで相手の刃が自分に向かないよう手首を下から制する点が要（師範差あり）。
**用語**：[[五教]] [[短刀取り]]

### 4-4-6 [[四方投げ]]（しほうなげ）
- **技名**：四方投げ／英 Shihonage, Four-Direction Throw。語源：四方どこへでも投げられることから（出典：syslinkams）。
- **概要**：相手手首を取り、腕をくぐって180度背転し、刀を斬るように腕を振り下ろし、肘を頭後ろに屈曲させ倒す（出典：Wikipedia、真誠館）。5級（片手取り四方投げ）。代表基本三技の一つ。

**【取り】動作分解（逆半身片手取り・表）**
1. 掴まれた手を手刀で導きつつ相手を伸ばして崩す。
2. 相手腕の下へ入身、腕を折り畳み肩へつける。
3. 180度背転（転身/転換）、常に体は垂直。
4. 送り足で踏み出し、伸張力で斬り下ろし投げる。
5. 極め：相手手を相手の耳に押しつけ制する（出典：たつひと合気道技法）。

**【取り】6部位一言**：目＝相手を見る、顔＝投げる方向、肩＝上げない（垂直維持）、腹/帯＝丹田を回し背転、膝＝低く（背が低い相手には腰を落とす）、足＝送り足で入る（相手との空間を空けない）。

**【取り】超詳細**
- よくある誤り：腕を引っ張る／体を反らす／相手と離れて隙間ができ返される。
- 師範差：投げ方（伸張で斬り下ろす／重力で落とす／空中四方投げ）が多様（出典：たつひと）。審査は斬り下ろしが基本。
- 安全：相手の肩・肘・手首を痛めやすい最も注意すべき技の一つ。ゆっくり、受身のできる相手と。

**【受け】動作分解**：片手を掴む→崩される→腕をくぐられ肩・肘が畳まれる→無理に逆らわず体を回して前受身／後ろ受身。
**【受け】6部位一言**：目＝取りを追う、顔＝畳を打たない、肩＝畳まれに従う、腹/帯＝回転、膝＝畳む、足＝回って受身。
**【受け】詳細・超詳細**：危険＝肘を突っ張る、手首を固める。良い受け＝早めに体を回転させ肩を逃がす。
**表裏**：表＝相手前方へ入身して斬る、裏＝転換して相手背後へ回して斬る（側面入身捌きと転身捌きの2系統がある、出典：たつひと）。
**関連**：半身半立ち四方投げ、横面打ち四方投げ、剣の斬り下ろしと同じ体運用。
**用語**：[[伸張力]] [[転身]] [[残心]]

### 4-4-7 [[入身投げ]]（いりみなげ）
- **技名**：入身投げ／英 Iriminage, Entering Throw（習得に時間を要するため俗に "20-year technique" と呼ばれる）。
- **概要**：相手側背へ入身し首を制し、転換で前へ導き崩し、起き上がる相手の頭を肩口へ引き寄せ、手刀を下から円く差し上げ斬り下ろして仰向けに倒す（出典：weblio、Wikipedia）。5級（正面打ち入身投げ）。代表基本三技。
**【取り】6部位一言**：目＝相手全体、顔＝投げる方向（最後に相手頭方向）、肩＝抜く、腹/帯＝丹田で導き垂直残身、膝＝低く、足＝入身→転換。
**【取り】超詳細**
- よくある誤り：腕で首を巻き倒そうとする（力技）／相手を追いかける。
- コツ：相手を自分の側に「呼吸で導く」。重力崩しはし過ぎると潰れて技が終わる（出典：たつひと）。
- 師範差：吉祥丸系は大きな円で流す、岩間系は接触を保ち直線的。
**【受け】**：崩され前へ→起き上がり→首を制され後ろへ倒れ後ろ受身。危険＝首に力を入れて逆らう。良い受け＝取りの導きに沿い後ろ受身。
**用語**：[[入身]] [[転換]] [[呼吸力]]

### 4-4-8 [[小手返し]]（こてがえし）
- **技名**：小手返し／英 Kotegaeshi, Wrist-Return Throw。投げ固め技。3級（正面打ち小手返し）から本部審査に登場（出典：たつひと）。
- **概要**：相手手首を取り、入身・転換で崩し、反対手を手の甲にかぶせ手首を返して肘関節を屈曲、仰向けに投げる（出典：weblio）。「合気道といえば小手返し」と言われる代表技。

**【取り】動作分解（正面打ち・表）**
1. 相手の打ちの線を外し重力で落とし、入身で側面裏へ。
2. 肩口から滑り下ろし相手手の甲を親指側から掴む。
3. 伸張力で真中下方へ押し落とし、背面転換。
4. 反転し体を開き小手返しで投げる。
5. 投げたまま／二教の極めで抑える2通り（出典：たつひと）。

**【取り】6部位一言**：目＝相手全体、顔＝投げ方向、肩＝抜く、腹/帯＝丹田で返す、膝＝低く、足＝入身→転換→反転。
**【取り】超詳細**
- よくある誤り：手首だけ捻る（かからない）。相手の四指を指先方向へ丸めると効く（出典：fransowa）。
- 師範差：崩し方・返し方・投げ方に道場差が大きい（出典：修徳館）。
- 安全：手首・肘を痛めやすい。演武は飛び受身だが稽古は後ろ受身から。
**【受け】**：手首を返され→崩れ→飛び受身または後ろ受身。危険＝手首を固め逆らう。良い受け＝返しに合わせ跳ぶ／転がる。
**表裏あり**。関連：交差取り小手返し（練習用）、突き小手返し。
**用語**：[[小手返し]] [[伸張力]] [[飛び受身]]

### 4-4-9 [[回転投げ]]（かいてんなげ）
- **技名**：回転投げ／英 Kaitennage, Rotary Throw。[[内回転]](uchi)・[[外回転]](soto)。3級（突き回転投げ）等。
- **概要**：相手腕を矢筈（やはず）に取り、肩を軸に上方へ押し上げ、頭を下げさせ、腕を相手の他方の肩方向へ回し押し投げる（出典：たつひと）。
**【取り】超詳細**：前腕伸張力と重力掛けで崩す。腕を握らず矢筈で操作するのは前腕の伸張力を100%使う仕掛け（出典：たつひと）。内回転＝相手の内側から、外回転＝外側から。
**用語**：[[矢筈]] [[伸張力]]

### 4-4-10 [[天地投げ]]（てんちなげ）
- **技名**：天地投げ／英 Tenchinage, Heaven-and-Earth Throw。両手取りが基本。3級（両手取り天地投げ）。
- **概要**：両手を掴ませ、一方を上（天）・一方を下（地）に切り分け、側面に入身して崩し投げる（出典：広島会）。
**【取り】6部位一言**：目＝相手、顔＝入身方向、肩＝抜く、腹/帯＝丹田に相手の力を吸収し返す（出典：ihope）、膝＝低く入身、足＝側面へ入身。
**【取り】超詳細**
- よくある誤り：天の手を外側に切り上げる（崩れない、内側が正）。押すのではなく吸い込む（出典：YouTube天地投げ）。
- 師範差：表＝同半身で側面へ、裏＝転換して投げる、と分類する道場が多い（出典：ameblo takemusu1）。
**用語**：[[天]] [[地]] [[丹田]]

### 4-4-11 [[腰投げ]]（こしなげ）
- **技名**：腰投げ／英 Koshinage, Hip Throw。1級（腰投げ5技）。
- **概要**：相手を腰に乗せて回転させ落とす。柔道の腰技に類似。
**【取り】超詳細**：取りは支点（シーソーの中心）、受けは板。上下動で投げる（前へ投げない）。足の引き付けが遅いと受けが自分の足上に落ち危険（出典：aikidomemo、saikyo.org）。腰の高さを受けのへそより下に。
**用語**：[[腰投げ]]

### 4-4-12 [[十字投げ]]／[[十字絡み]]（じゅうじなげ）
- **技名**：十字投げ／英 Jujinage, Juji Garami, Cross-Arm Throw。2級（後ろ両手取り十字投げ）。
- **概要**：相手の両腕を十字に交差させ固めて投げる。
**【取り】超詳細**：肘を交差させて相手の自由を奪う。肘・肩を痛めやすく、受けは腕を組まれたまま前受身をとる必要があり危険度が高い（安全注意）。
**用語**：[[十字絡み]]

### 4-4-13 [[呼吸投げ]]（こきゅうなげ）
- **技名**：呼吸投げ／英 Kokyunage, Breath/Timing Throw。名称のない投げの総称（[[合気投げ]]）。片手取り・諸手取り等で多数。
- **概要**：呼吸力とタイミングで相手を導き投げる、形の定まらない投げの総称。
**【取り】超詳細**：崩しと入身のタイミングが命。師範ごとに無数の変化がある（会派・師範差が最も大きい）。
**用語**：[[呼吸力]] [[合気投げ]]

### 4-4-14 [[隅落とし]]（すみおとし）
- **技名**：隅落とし／英 Sumi Otoshi, Corner Drop。呼吸投げの一種。
- **概要**：相手の斜め後ろ（隅）へ崩して落とす。内転換で隅落とし系の崩しをつくる（出典：合気道ブログ）。
**用語**：[[隅落とし]]

### 4-4-15 [[肘極め]]／[[後ろ落とし]]
- 肘極め：英 Hiji Kime（Osae）。肘関節を極める技。
- 後ろ落とし：英 Ushiro Otoshi。相手を後方へ落とす。
（いずれも師範・道場により命名・分類に差がある）

### 4-4-16 座技（[[座技]]、suwari waza）
座って行う技。正面打ち一教〜四教、座技呼吸法（呼吸動作）が中核。膝行での入身・転換が要。腰・下半身の鍛錬目的（出典：weblio）。
### 4-4-17 半身半立ち技（[[半身半立ち]]、hanmi handachi）
取りが座り受けが立つ。片手取り四方投げ、両手取り四方投げ、片手取り回転投げなど。2級以降で頻出。

## 4-5 武器技の基礎（初段まで）
初段科目に太刀取り・木刀技、杖取り・杖技、短刀取りが含まれる（USAF初段・本部二段で短刀取り、出典：USAF、合気会）。「剣を持ったら[[合気剣]]、杖を持ったら[[合気杖]]」と言われ、体術と同一原理とされる（出典：aikido-shiga）。斉藤守弘は開祖の武器技を体系化し、7の素振り・20の素振り・31の杖・13の杖・組太刀・組杖などを整理した（出典：Wikipedia「斉藤守弘」、どう出版）。初段までは主に短刀取りと素振りの基本に触れる範囲。

# 第5章 海外での合氣道と技の英名

## 5-1 海外普及史
戦後、開祖の高弟が各国へ派遣・移住し普及した。
- **フランス**：1950年代に[[望月稔]]・阿部正らが基礎を築き、最も早く普及に成功（出典：Wikipedia「田村信喜」）。[[田村信喜]]（1933年3月2日－2010年7月9日、1999年フランス国家功労勲章シュヴァリエ章受章）は、1964年に結婚を機にマルセイユへ渡り45年間指導した（出典：日本語版Wikipedia、WEB秘伝）。
- **アメリカ**：[[山田嘉光]]（本部内弟子、英語堪能で米軍基地指導を担当）が渡米しUSAFの中心に。
- **イタリア**：[[多田宏]]（早大出身、中村天風にも師事、イタリア合気会創立）（出典：多田塾、note世界文化社）。
- **イギリス**：[[金井満也]]・[[千葉和雄]]らが渡英。後にBAFの技術責任者は金塚実（[[Minoru Kanetsuka]]、8段、2019年逝去）が務めた（出典：Greenwich Aikido handbook）。
- 内弟子仲間：小林保雄・浅井勝昭・栗田豊・五月女貢ら。合気道初の外国人内弟子アンドレ・ノケも来日（出典：Wikiwand「田村信喜」）。
- 小林道場は18か国に指導者派遣、1991年「むすび基金」設立（出典：小林道場）。

## 5-2 主要国の組織
- **[[USAF]]**（United States Aikido Federation）：1976年のIAF創設に伴い設立、東部・中西部・西部・ハワイに区分（出典：Aikido Journal）。
- **[[ASU]]**（Aikido Schools of Ueshiba）：開祖の内弟子であった[[五月女貢]]（Mitsugi Saotome）師範が創設した米国の組織。
- **[[British Aikido Federation]]**（BAF）：合気会系の英国代表団体、色帯なし。
- **[[British Aikido Association]]**（BAA）：富木／昭道館系（合気会ではない）、色帯採用。
- フランス：[[FFAAA]]・[[FFAB]]。ドイツ：[[Aikikai Deutschland]]・[[DAB]]・[[AUD]]。
- 合気会系の各国連盟は本部（Aikikai）を頂点にIAFへ加盟する。

## 5-3 海外の段級制度・帯色・袴
- **帯色**：合気会本部は級位＝白帯、初段＝黒帯＋袴が原則（出典：Wikipedia "Kyū"）。海外でも合気会系（BAF、USAF）は原則白帯のみ（出典：USAF New Student Guide、Chester Aikido）。ただし**ドイツの合気会系連盟（DAB, AUD）は色帯を体系採用**：6級白→5級黄→4級橙→3級緑→2級青→1級茶（出典：aikido-hamminkeln.de、aikido-union.de）。フランス（FFAAA）は「原則は昇段まで白帯、教師の裁量で色帯を提案可（特に子供）」（出典：FFAAA公式）。**英国で色帯を使うのは富木系のBAA**（赤・白・黄・橙・緑・青・茶、出典：BAA公式）であり、合気会系のBAFは白帯のみである点に注意。
- **袴の着用時期**：本部は男性＝初段、女性＝3級から（出典：Guillaume Erard、daishizen.org）。海外は道場差が大きく、5級（最初の審査）〜3級〜1級〜初段まで幅がある。ASUは最初の審査（5級）合格で袴（出典：MartialTalk）。BAF（Greenwich）は女性6級以上で許可制。歴史的には戦前〜戦後直後は全員が入門初日から袴を着けたが（塩田・五月女の証言）、経済的理由から1950年代半ば〜後半に「初段まで袴不要」ルールが生まれたとされる（出典：TAE Journal Ed.11、Saotome『The Principles of Aikido』1989）。岩間系（斉藤守弘）本流も最終的には初段以上に袴を限定したとの証言がある（出典：TAE Journal）。

## 5-5 訳語のニュアンス問題
- 「投げ（nage）」＝throw、「極め／抑え（osae/kime）」＝pin／lock。抑え技は "pin"、関節技は "joint lock"。
- 「受け（uke）」：receiver か attacker か。ukeは技を受ける側だが攻撃を仕掛ける側でもある（New World Encyclopedia）。役割の二重性が訳を難しくする。
- 「取り／仕手（tori/shite）」：nage（thrower）とも呼ぶが、投げない固め技もあるため tori/shite が正確。日本の合気会では実際には nage より tori や aite（相手）を使うことが多いとの在日実践者の証言がある（出典：AikiWeb、Chris Farnham）。
- 語源：uke←ukeru（受ける）、nage←nageru（投げる）。手首取り等の「-dori／-tori」は掴む技、「-nage」は投げる技（出典：AikiWeb、Dave Lowry『In the Dojo』）。

## 5-6 海外の稽古文化の違い
- 稽古は協力的で競争的でない（出典：Northwestern Aikido FAQ）。
- 号令：道場により先輩が「正面に礼」「先生に礼」「お互いに礼」と唱える場合と、無言で行う場合がある（出典：Northwestern FAQ）。
- 質問文化：日本では上位者に直接質問・訂正しない文化。欧米は質問が活発（出典：Linda Eskin "Grab My Wrist"）。
- 「気」の捉え方：日本人学生は「穏やか・柔らか・丸い」、米国学生は「硬い・執拗」と表現する研究がある（出典：Kung Fu Tea／Benjamin Judkins紹介の研究）。
- 試合の不在：受けは clean ukemi、取りは clean waza を行い、妨害はしない（出典：Aikido Journal, Stanley Pranin）。

# 第6章 単語集（あいうえお順・骨子）

> 各語：読み／ローマ字／英語／定義／関連語。`content/glossary/` で1語1ファイルに展開し、200語以上へ拡張する。

## あ行
- **合気**（あいき / aiki / harmonized energy）：相手と争わず気を合わせること。開祖は「合氣とは愛なり」と説いた。関連：和合、呼吸力。
- **相半身**（あいはんみ / ai hanmi / mutual stance）：互いに同じ側の足を前にする構え。対：逆半身。
- **合気会**（あいきかい / Aikikai）：開祖直系の最大会派、公益財団法人。
- **合気剣**（あいきけん / aiki ken）：合気道の剣術。関連：組太刀、素振り。
- **合気杖**（あいきじょう / aiki jo）：合気道の杖術。関連：31の杖、組杖。
- **合気投げ**（あいきなげ / aiki nage）：呼吸投げの別称。
- **合気上げ**（あいきあげ / aiki age）：座技呼吸法で相手を持ち上げ崩す動作。
- **当身**（あてみ / atemi / strike）：崩しや牽制の打撃。技の入口で用いる。
- **綾部**（あやべ）：大本教本拠地、植芝塾の地。
- **一教**（いっきょう / ikkyo）：腕抑え。基本の固め技。関連：二〜五教。
- **一教運動**（いっきょううんどう / ikkyo undo）：一教の腕の軌道を反復する準備運動。

# 第7章 アプリ設計への示唆（付録）

## 7-1 6部位分解解説の共通観点（汎用チェックリスト）
- **目**：どこを見るか（相手全体か、投げる方向か、指先か）。一点凝視の可否。
- **顔**：向き（相手正面か、崩す／投げる方向か）。受けは畳を打たない向き。
- **肩**：脱力（撫で肩）か上げるか。腕力に頼らない指標。
- **腹/帯（丹田・腰）**：正中線の向き、体重移動、回転の主体。技の力源。
- **膝**：曲げ具合、居着かない、極め時の着き方（相手に近い足から）。
- **足**：足捌きの種類（送り足/継ぎ足/入身/転換）、つま先の向き、手足同期。

## 7-2 アニメーションのキーフレーム候補（止めるべき瞬間）
1. **接触**（攻撃を受けた／掴まれた瞬間）＝間合い・当身。
2. **崩し完了**（相手の重心が崩れた瞬間）＝最重要。
3. **入身/転換の頂点**（体が入れ替わる瞬間）。
4. **投げ/極めの発動直前**。
5. **残心**（技後の姿勢）。

## 7-3 初心者が躓きやすいポイント
| 躓き | 該当技 | 対応 |
|---|---|---|
| 手先で押す | 一教・入身投げ | 丹田・体重移動を可視化 |
| 手首だけ捻る | 小手返し・二教 | 崩し先行を強調 |
| 隙間ができ返される | 四方投げ | 相手と密着を明示 |
| 天の手を外に切る | 天地投げ | 内側切り上げを強調 |
| 後頭部を打つ | 後ろ受身 | 顎を引く・肩で回る |
| 足が止まる | 全般 | 足捌きの矢印表示 |

## 7-4 稽古の安全上の注意
- 関節技（二教・三教・小手返し・四方投げ・十字投げ）は激痛・故障リスク。ゆっくり、相手のタップで即緩める。
- 受身は「しゃがみ→立位→回転→跳躍」の順で段階的に。後頭部保護（顎を引く）を最優先。
- 四方投げ・小手返し・十字投げは肩・肘・手首の故障が多い。受けの技量に合わせ強度調整。
- 初段までの怪我予防：準備運動（手首運動・鳥船）を十分に、無理な飛び受身を強要しない。
