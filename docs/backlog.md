## 3. Claude Code への投げ方

**1タスク＝1プロンプト。テンプレ：**
```
タスク: T16 markers.ts
参照: docs/animation-spec.md §6, docs/design-complete.md「一時停止→吹き出し」, SKILL.md
やること: 一時停止時に6部位の関節座標を取得し、HTMLレイヤーにl1吹き出しを描く
完了条件: 6つが正しい関節に乗る／再生中は消える／VoiceOverで読める
禁止: touch-action:none をページ全体に付けない／部位ID命名規則から外れない
終わったら: 変更ファイル一覧と、実機で確認してほしい操作を3行で
```
- 依存タスクが未完なら着手しない。
- 1プロンプトで複数タスクを混ぜない（レビューが効かなくなる）。
- 仕様の解釈に迷ったらOpusは**実装せず質問**する（CLAUDE.mdに明記済み）。

## 4. レビューチェックリスト（ディレクター用）

### 4-1. 全タスク共通（受け入れ時に毎回）
- [ ] 完了条件を**自分の目で**確認した（Opusの報告だけで済ませない）
- [ ] `npm run build:content` と `npm run build` が警告0
- [ ] 変更が SKILL.md の禁止事項に触れていない（動画をアニメ本体に使う／ズーム禁止／ID命名逸脱／スタック変更）
- [ ] 新しい依存を追加した場合、理由が1行で書かれている
- [ ] 実機（iOS）で該当機能を1回触った

### 4-2. マイルストーン別

**M1（Day2）デプロイ経路**
- [ ] 公開URLがオフラインで開く
- [ ] Yuji Syuku が表示される（フォールバック明朝になっていない）

**M2（Day6）アニメ**
- [ ] 一教の全kfで骨が伸び縮みしていない
- [ ] 視点切替で受けが手前・濃墨になり、`at` が保持される
- [ ] 自分がエディタで直した形が反映されている

**M3（Day10）インタラクション**
- [ ] 止める→6吹き出し→タップで1段→ピンチで1段→戻るで1段閉じる、が**説明なしで**分かる
- [ ] ページ全体のピンチズーム（標準）が生きている
- [ ] 戻るボタンを押しすぎてアプリから抜けない（スタック底で1回だけ抜ける）

**M4（Day13）品質**
- [ ] 機内モードで一教が全部動く
- [ ] Lighthouse 90+ ×3
- [ ] VoiceOverで部位名と解説が読める

### 4-3. 部員テスト台本（Day14・1人5分）
1. 「一教の技を止めて、膝の説明を見てください」（誘導なし）
2. 「もっと詳しく見てください」（ピンチかタップかを観察）
3. 「元に戻してください」（戻るボタンを使うか観察）
4. 「入身って何か調べてください」（用語リンク）
5. 感想：分かりにくかった操作を1つ

記録欄：達成／所要秒／迷った操作／一言
