## 0. 決定事項サマリ

| 項目 | 決定 |
|---|---|
| 技ファイル単位 | **技×表裏で1ファイル**（`ikkyo-omote.md` / `ikkyo-ura.md`）。攻撃法は内包 |
| 攻撃法の扱い | 基本攻撃法を全キーフレームで書き、他の攻撃法は**差分（override）のみ** |
| 解説の粒度 | **キーフレームごと**に 受け/取り × 6部位 × 5階層 |
| キーフレーム | 技ごとに**可変**。意味名IDと進捗率 `at` を持つ |
| 階層 | **5階層**、上限 l1=20 / l2=60 / l3=150 / l4=300 / l5=600 字、役割固定 |
| 受け | 取りと**同じ分量を必須** |
| 信頼マーク | **文単位**。`{{f:}}`事実／`{{v:}}`師範差／マークなし＝一般的な指導 |
| 用語リンク | `[[用語]]`、エイリアス `[[表示|正規名]]`、単語集は**1語1ファイル** |
| 動画 | 技・用語とも複数可、開始秒可。講師は**四段以上 or 師範経験者** |
| 試験範囲 | 基礎（半身・構え・体捌き・膝行・受身・呼吸法・攻撃法）＋5級科目 |

## 2. 技ファイル（techniques/, kihon/）

### 2-1. フロントマター

```yaml
---
id: ikkyo-omote            # ファイル名と一致
type: technique            # technique | kihon
name_ja: 一教（表）
reading: いっきょう おもて
name_en: [Ikkyo omote, First control (front)]   # 複数可
aliases: [腕抑え, 第一教]
form: omote                # omote | ura | none
rank: 5kyu                 # 5kyu|4kyu|3kyu|2kyu|1kyu|shodan|kihon
category: osae             # osae(固め) | nage(投げ) | kokyu | kihon | ukemi | attack
default_attack: shomen-uchi
attacks: [shomen-uchi, katate-dori, kata-dori]   # 先頭がdefault
videos:
  - url: https://www.youtube.com/watch?v=XXXX&t=95
    instructor: 〇〇 〇〇
    rank: 7dan             # Ndan | shihan | unknown
    note: 表の入身と肘の制し方が明瞭
sources:                   # 本文の @src:key から参照
  aikikai-shinsa: 合気会「審査要項」 https://www.aikikai.or.jp/...
  ueshiba1962: 植芝吉祥丸『合気道』1962
status: draft              # draft | review | approved
reviewer:                  # approved時に必須
---
```

**バリデーション**
- `id` ≠ ファイル名 → エラー
- `attacks[0]` ≠ `default_attack` → エラー
- `videos[].rank` が `4dan` 未満かつ `shihan` でない、または `unknown` → **警告**（緩め運用）
- `status: approved` で `reviewer` 空 → エラー

### 2-2. 本文構造（見出し規約）

```markdown
## 概要
（技の目的・原理・どの級で出るか。3〜5文。用語は[[リンク]]）

## キーフレーム
### [kf] contact | 接触 | at=0.15
（このキーフレームの状況説明 1〜2文）
#### 取り
**目**
- l1: …
- l2: …
- l3: …
- l4: …
- l5: …
**顔**
- l1: …
（以下 肩・腹（帯）・膝・足）
#### 受け
**目**
- l1: …
（取りと同じ構造）

### [kf] kuzushi | 崩し | at=0.35
…

## 攻撃法バリエーション
### [attack] katate-dori | 片手取り
overrides: [contact, kuzushi]
（差分説明 1〜2文）
#### [kf] contact | 接触 | at=0.15
##### 取り
**目**
- l1: …
（上書きするキーフレームのみ、全部位・全階層を書く）

## 関連
- 表裏の相方: [[一教（裏）]]
- 派生: [[二教]] [[入身投げ]]
```

**見出しの機械可読ルール**
| 記法 | 意味 |
|---|---|
| `### [kf] {id} \| {日本語名} \| at={0.0〜1.0}` | キーフレーム定義。`id` は英小文字、技内で一意 |
| `#### 取り` / `#### 受け` | ロール（`tori` / `uke`）。**両方必須** |
| `**目**` `**顔**` `**肩**` `**腹（帯）**` `**膝**` `**足**` | 部位。**この6表記固定**、順序固定 |
| `- l1:` 〜 `- l5:` | 階層。**5つ必須** |
| `### [attack] {slug} \| {日本語名}` ＋ `overrides: [...]` | 攻撃法差分。overridesに書いたkfのみ本文に記述 |

### 2-3. キーフレーム（■提案：お任せ回答分）

- **IDは意味名**（連番ではなく）。共通語彙を優先し、足りなければ技固有名を追加。
  - 共通語彙：`kamae`（構え）`contact`（接触）`kuzushi`（崩し）`irimi`（入身）`tenkan`（転換）`nage`（投げ）`osae`（極め/抑え）`zanshin`（残心）
  - 固有例：`shihonage-omote` の `kuguri`（腕くぐり）、`kokyuho` の `age`（上げ）
- **`at`** はアニメ全体を 0.0〜1.0 とした進捗率。単調増加必須。最初のkfは 0.0 でなくてよい（構え区間を許容）。
- 数は可変だが **最低3**（接触・崩し・極め/投げ に相当するもの）。
- 静的な基礎（半身・構え）は kf 1つ（`hold`, at=0.5）で可。

### 2-4. 5階層の役割と上限

| 階層 | 上限（全角=1） | 役割 | 文体 |
|---|---|---|---|
| l1 | 20字 | 吹き出し。何を意識するか | 体言止め／命令形 |
| l2 | 60字 | 具体的に何をするか | 常体・1〜2文 |
| l3 | 150字 | なぜそうするか（原理・因果） | 常体 |
| l4 | 300字 | よくある誤りと修正法 | 「誤り：」「修正：」で始める |
| l5 | 600字 | 師範差・歴史・武器技/他技との関係 | `{{v:}}` `{{f:}}` を多用 |

- 上限超過 → **警告**（+10%超はエラー）。
- l1 は句点「。」を付けない。l1 に信頼マークは使わない（吹き出しは一律「一般的な指導」扱い）。
- l4 は必ず「誤り：」「修正：」の2要素を含む。

### 2-5. 信頼マーク

| 記法 | 意味 | 表示色（トークン） |
|---|---|---|
| `{{f:文。}}` | 事実（沿革・審査規定・公式表記・出典あり） | 墨・濃 `--sumi-nou` |
| （マークなし） | 一般的な指導 | 墨・淡 `--sumi-tan` |
| `{{v:文。}}` | 師範・会派により異なる | 朱 `--shu` |

- **1文＝1マーク**。マークは文をまたがない（`{{f:A。B。}}` は禁止、`{{f:A。}}{{f:B。}}` と書く）。
- 出典参照は文末に `@src:key`（任意）：`{{f:五級科目に含まれる。@src:aikikai-shinsa}}`
- `{{f:}}` に `@src` が無い場合 → **警告**。
- 入れ子禁止。`[[用語]]` はマーク内に置いてよい。

### 2-6. 用語リンク

- `[[入身]]` → glossary の `name_ja` または `aliases` と一致で解決 → `#/glossary/irimi`
- 表記ゆれ：`[[入り身|入身]]`（**表示|正規名**）。
- 未解決 → **警告**＋ビルド時に `unresolved-terms.txt` を出力。
- 1つの解説文（l1〜l5）で同一用語は**初出のみ**リンク（ビルド時に2回目以降を自動除去）。

### 2-7. 文体規則

- 常体（だ・である）。数字は半角。「取り／受け」「表／裏」表記固定（「仕手」「捕り」は本文で使わない）。
- 部位名は本文でも「目・顔・肩・腹（帯）・膝・足」に統一。
- 左右は「左」「右」ではなく「前足／後ろ足」「掴まれた手／自由な手」で書く（半身の左右反転に耐えるため）。

## 3. 単語集ファイル（glossary/）

```yaml
---
id: irimi
name_ja: 入身
reading: いりみ
romaji: irimi
name_en: [Irimi, Entering]
aliases: [入り身]
category: taisabaki      # taisabaki|waza|kihon|shiso|rekishi|soshiki|buki|hito
related: [tenkan, irimi-tenkan, iriminage]
videos:
  - url: https://www.youtube.com/watch?v=YYYY&t=30
    instructor: 〇〇 〇〇
    rank: shihan
    note: 入身と転換の違いを実演
status: draft
---
## 定義
（60字以内・1〜2文。アプリのホバー/一覧に使う）

## 詳細
（自由。信頼マーク・[[用語]]使用可）

## 関連
- [[転換]] と対をなす。
```

- `related` は他glossaryの `id`。未存在 → 警告。
- `category: hito`（人物）は `name_en` に生没年を含めてよい。

## 4. 動画リンク規約

- 形式：`https://www.youtube.com/watch?v=ID&t=秒` または `https://youtu.be/ID?t=秒`
- **講師基準**：`rank` が `4dan` 以上、または `shihan`。満たさない／`unknown` は警告のみ（掲載は可）。
- 1エントリ1動画。同じ動画の別秒は別エントリ。
- `note` は必須（何が分かる動画か、30字以内）。
- アプリはリンクのみ表示（埋め込み再生はしない：オフライン・通信量配慮）。

## 7. 執筆ワークフロー

1. **原稿md（第1〜7章）から該当技の記述を抜き出す**（Fable）
2. 本仕様の雛形にはめ、kf を切る（Fable＋ディレクター）
3. 6部位×5階層×受け/取りを埋める（Fable）
4. `npm run build:content` で警告0にする（Opus）
5. `status: review` → 師範/上級生が校閲 → `approved` ＋ `reviewer` 記入（ディレクター）
6. アプリは draft/review も表示するが、**朱の「校閲前」バッジ**を出す

## 8. 実例：正面打ち一教（表）— キーフレーム「接触」

> 内容は例示。師範校閲前（status: draft）。

```markdown
---
id: ikkyo-omote
type: technique
name_ja: 一教（表）
reading: いっきょう おもて
name_en: [Ikkyo omote, First control (front)]
aliases: [腕抑え]
form: omote
rank: 5kyu
category: osae
default_attack: shomen-uchi
attacks: [shomen-uchi]
videos: []
sources:
  aikikai-shinsa: 合気会「審査要項」
status: draft
---

## 概要
[[正面打ち]]に対し、[[入身]]しながら相手の肘と手首を[[手刀]]で制し、前方へ崩して腹這いに抑える基本の固め技。{{f:合気会審査要項では五級科目に含まれる。@src:aikikai-shinsa}} 二教〜四教の土台であり、体捌きはほぼ共通する。

## キーフレーム
### [kf] kamae | 構え | at=0.0
[[相半身]]で対峙。互いに右半身。

### [kf] contact | 接触 | at=0.15
受けの正面打ちが振り下ろされる瞬間、取りは後ろ足を踏み込み、手刀で相手の肘と手首に触れる。

#### 取り
**目**
- l1: 相手の中心を見る
- l2: 一点を凝視せず相手全体を視野に収め、打ってくる手ではなく胸の中心を見る。
- l3: 手刀に目を奪われると反応が遅れ、肩に力が入る。中心を見ることで打ちの起こりを早く察知でき、入身の方向も自然に定まる。
- l4: 誤り：打ってくる手を目で追い、頭が下がって腰が引ける。修正：相手の襟元に目印を置き、そこを見続けたままゆっくりした正面打ちを捌く反復から始める。
- l5: {{v:「[[遠山の目付け]]」で全体をぼんやり見るよう指導する師範と、相手の目を見るよう指導する師範がいる。}}{{f:遠山の目付けは剣術由来の言葉で、『五輪書』の「観の目」に通じるとされる。}}

**顔**
- l1: 相手正面に向ける
- l2: 顎を引き、顔を相手の[[正中線]]に正対させる。打ちを避けて横を向かない。
- l3: 顔の向きは体幹の向きを決める。顔が逃げると腰も逃げ、入身が浅くなって肘に手刀が届かない。
- l4: 誤り：打たれる恐怖で顔を背け、体が開いてしまう。修正：ゆっくりした打ちに対し、正対したまま踏み込むだけの稽古を繰り返す。
- l5: {{v:養神館系は顎を強く引く姿勢を明確に指導する一方、合気会本部では自然体を重視する師範が多い。}}

**肩**
- l1: 力を抜き落とす
- l2: 両肩を落とし、手刀は肩からではなく腰・[[丹田]]の動きで上げる。
- l3: 肩が上がると腕の力で受けることになり、相手の打ちの力と正面衝突する。肩を落とすことで打ちを止めるのではなく、合わせて導くことができる。
- l4: 誤り：打ちを止めようとして肩がすくむ。修正：手刀を上げる前に一度息を吐いて肩を落とす。手刀の上げ下げは[[一教運動]]で反復し、腕の運動にしない。
- l5: {{f:準備運動の一教運動はこの手刀の軌道を単独で反復するものである。}}{{v:岩間系は接触の瞬間に相手を止める強い接触を、本部系は流れの中で触れる軽い接触を指導する傾向がある。}}

**腹（帯）**
- l1: 丹田を相手へ向ける
- l2: 帯の結び目が相手の中心に向くよう腰を切り、体重を前足に乗せ始める。
- l3: 手刀の力は丹田の移動から生まれる。帯の向きがずれると手だけで相手の腕を上げようとし、[[崩し]]が効かない。
- l4: 誤り：腰が後ろに残り上体だけが前に出る。修正：踏み込みと同時に帯を相手へ向ける意識を持ち、鏡で帯の向きを確認しながら反復する。
- l5: {{v:丹田の捉え方は師範により「臍下三寸」「腰全体」など表現が異なる。}}{{f:心身統一合氣道は臍下の一点を中心概念として体系化した。}}

**膝**
- l1: 軽く曲げ低く保つ
- l2: 両膝を緩め、踏み込む前足の膝は相手方向へ向ける。伸びきらない。
- l3: 膝が伸びると重心が上がり、相手の打ちに押し戻される。低い膝が入身の推進力になる。
- l4: 誤り：踏み込みで前膝が内側に入り、膝を痛める。修正：つま先と膝の向きを常に一致させ、踏み込み幅を小さくして反復する。
- l5: 膝の高さは相手の身長により調整し、相手が低いほど自分も低く入る。{{v:[[座技]]の一教で膝の使い方を先に身につけさせる師範もいる。}}

**足**
- l1: 後ろ足を踏み込む
- l2: 相半身から後ろ足を相手の外側へ踏み込み、前足のつま先は相手へ向ける。
- l3: 手足が同時に動くことで打ちの線から体が外れ、同時に相手の肘へ手刀が届く距離になる。足が遅れると手だけが先行して衝突する。
- l4: 誤り：手が先に出て足が止まる。修正：「足から入る」と声に出しながら踏み込みだけを反復し、手刀は後から添える。
- l5: {{v:表技の一歩目を「後ろ足の踏み込み」とするか「前足の[[送り足]]」とするかは師範により異なる。}}{{f:合気会審査要項では正面打ち一教は五級科目に位置づけられる。@src:aikikai-shinsa}}

#### 受け
**目**

- l2: 相手の額を見て打つ。取りの手に目を奪われない。
```
