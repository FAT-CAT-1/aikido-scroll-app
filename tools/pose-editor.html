検証
  • ファイルを開くと、15関節の欠落・at の重複・骨長 ±15% 超・地面より下などを表示します。
使い方（5ステップ）
  1. 「ファイルを開く」で content/poses/ikkyo-omote.pose.json を選ぶ（ファイルをこの画面にドラッグしてもよい）。
  2. 上の「kf」で直したいキーフレームを選び、自分でその形を取ってから、違う関節の丸をドラッグして合わせる。
  3. 「残像」を ON にして前後の kf（薄い灰色）と見比べる。不自然なら「＋kf追加」で中間ポーズを足す（原稿にも同じ kf を追加）。
  4. 「プレビュー再生」で流れを確認する（ここでは直線補間。正確な動きはアプリで確認）。
  5. 「保存」で JSON をダウンロードし、元の場所に上書き → Claude Code に「pose.json 更新した、反映して」と伝える。

操作のコツ：

  • 骨長ロック ON：手首・足首をドラッグすると肘・膝が自動で曲がる。肘・膝・肩などをドラッグするとその先が回転して付いてくる。腰をドラッグすると全身が移動。
  • Ctrlを押しながら腰をドラッグ：足首をその場に残して腰だけ上下・前後（膝が曲がる）。
  • Altを押しながらドラッグ：その関節だけ自由に移動（骨の長さが変わるので注意）。
  • 選択中の関節は ←↑→↓ で 1、Shift＋矢印で 10 動く。Ctrl+Z で元に戻す。
